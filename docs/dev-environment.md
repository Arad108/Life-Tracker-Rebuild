# Life Tracker — local Android development

All large Android files live on `D:`.

| Component | Path |
|---|---|
| Android Studio | `D:\Android\Android Studio` |
| Android SDK | `D:\Android\Sdk` |
| AVDs | `D:\Android\AVD` |
| Gradle cache | `D:\Android\Gradle` |
| Studio config/cache | `D:\Android\AndroidStudio` |
| NDK | `D:\Android\Sdk\ndk\27.1.12297006` |
| JDK | `D:\Android\Android Studio\jbr` (JDK 25) |

Emulator: `LifeTracker_Pixel7` — Pixel 7, Android 16 (API 36), x86_64, 4 GB RAM,
hardware acceleration via WHPX.

## Daily workflow

```powershell
# 1. Start the emulator (idempotent)
.\scripts\start-emulator.ps1

# 2. Start Metro with the dev client
.\scripts\start-metro.ps1

# 3. First time only / after native dependency changes: build + install
.\scripts\rebuild-dev-client.ps1

# 4. Launch the app
adb shell am start -n com.lifetracker.app/.MainActivity
```

Once the dev build is installed and Metro is running, edit any file under
`app/` or `src/` and the emulator updates through Fast Refresh. No rebuild is
needed for JS/TS, styles, copy or assets.

Rebuild the dev client only when you add/remove a native module, change
`app.json` native config, change permissions, or change the NDK/ABI setup.

## Capture a screen

```powershell
adb shell screencap -p /sdcard/screen.png
adb pull /sdcard/screen.png .\artifacts\screen.png
adb shell rm /sdcard/screen.png
```

## Windows long paths

React Native's generated native build produces object paths longer than 260
characters. The ninja 1.10.2 bundled with CMake 3.22.1 refuses those paths even
with `LongPathsEnabled=1`, so the SDK copy was replaced with ninja 1.12.1:

- Binary: `D:\Android\Sdk\cmake\3.22.1\bin\ninja.exe` (1.12.1)
- Original kept as: `D:\Android\Sdk\cmake\3.22.1\bin\ninja-1.10.2.exe.bak`

If the SDK is ever reinstalled, re-apply this replacement or the first
`:app:buildCMakeDebug[x86_64]` will fail with "Filename longer than 260
characters".

## Notes

- Debug builds are signed with the local debug keystore, separate from the
  production/EAS signing identity. The production package ID is unchanged
  (`com.lifetracker.app`).
- `android/` is generated by `npx expo prebuild`. Treat it as disposable; app
  code lives in `app/` and `src/`.
- The emulator is a disposable device. The original APK, screenshots and
  recovered artifacts are never installed over or modified.
